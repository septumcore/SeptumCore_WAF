Этот проект — моя страсть и стремление предоставить мощный и доступный инструмент для защиты ваших веб-ресурсов. Каждый релиз, каждая функция — это результат тысяч часов работы, вдохновленной идеей сделать интернет безопаснее. Ваша поддержка и активное участие в комьюнити — это то, что движет меня вперед!

---

**SeptumCore WAF CE** — это готовый edge-контур для защиты и управления веб-трафиком: WAF (Nginx + ModSecurity), аналитика атак, TLS, L4-стримы и единая панель управления.

Если коротко: вы получаете не просто фильтрацию запросов, а полноценный защитный периметр для сайтов, API и TCP/UDP-сервисов.

## Максимальная защита цифрового контура

`SeptumCore WAF CE` — это уровень зрелой инфраструктурной защиты: быстрое внедрение, прозрачное управление и устойчивость сервисов под нагрузкой.

- Защита веб-приложений и API на уровне L7.
- Противодействие ботам, HTTP Flood и массовым атакам.
- Централизованный контроль сертификатов, правил и маршрутизации.
- Быстрый запуск новых защищенных сервисов без долгих ручных операций.
- **Управление WAF-нодами:** Возможность распределять защиту по нескольким серверам (Worker Nodes) из единой Control Plane.

## Что это дает бизнесу

- Снижает риск инцидентов за счет автоматической блокировки подозрительного трафика.
- Ускоряет запуск новых защищенных приложений через единый UI и API.
- Упрощает эксплуатацию: сертификаты, логи, правила и маршрутизация управляются из одной панели.
- Помогает команде быстрее расследовать атаки благодаря real-time событиям и аналитике.

## Реальные возможности продукта

### Защита приложений

- WAF-ядро на базе `ModSecurity + OWASP CRS`.
- Обновление баз угроз (CRS + IP threat lists) прямо из интерфейса.
- Auto-Ban для HTTP Flood и bad-bot активности с настраиваемыми порогами и временем блокировки.
- Режим `Under Attack` с JS challenge-страницей для фильтрации массового вредоносного трафика.
- Глобальные и локальные allow/deny правила по IP/подсетям, включая временные блокировки.
- Кастомные WAF-правила с приоритетами и аудитом изменений.

### Трафик и отказоустойчивость

- Reverse proxy для веб-приложений (L7).
- Маршрутизация по путям (`prefix`, `exact`, `regex`) для микросервисных сценариев.
- Проверка доступности upstream-узлов и индикация состояния.
- L4 Proxy: TCP/UDP стримы с поддержкой SSL-терминации и ограничений по allowed IP.

## Маршрутизация и L4-контроль трафика

### Мониторинг узлов и балансировка

- **Здоровье upstream-серверов** — регулярные TCP health-check с отображением статуса в интерфейсе (`Проверка`, `Активен`, `Недоступен`)
- **Мгновенная диагностика** — автоматическое обновление доступности при изменении конфигурации
- **Режимы балансировки** — `Round Robin`, `Least Conn`, `IP Hash` для равномерного распределения и sticky-сессий
- **L7-маршрутизация** — сопоставление путей: `prefix`, `exact`, `regex`
- **Статус L4-стримов** — мониторинг доступности TCP/UDP подключений в реальном времени
- **Безопасное применение** — валидация и безопасный reload Nginx без простоев

### SSL и эксплуатация

- Выпуск сертификатов Let's Encrypt (включая SAN/мультидоменный формат).
- Автопродление сертификатов.
- Поддержка загрузки собственных `crt/key`.
- DSL-сценарий развертывания с автосозданием сертификата (`ssl auto`).
- Безопасная регенерация Nginx-конфигов с проверкой `nginx -t` и reload.
- Встроенный CLI-сброс пароля администратора.

## DSL + Zero-Touch SSL

Для инфраструктурных команд доступен DSL-режим: приложение, upstream и SSL можно включить одним декларативным описанием.

Пример:

```txt
app my_shop {
  domain shop.example.com
  domain api.shop.example.com
  upstream http://10.0.0.21:8080
  port 80
  port 443
  ssl auto
  waf on
  bot_protection on
}
```

Что происходит после применения:

- Создается приложение и конфигурация reverse proxy.
- Для доменов запрашивается Let's Encrypt сертификат.
- Сертификат сохраняется и подключается к Nginx.
- Конфиг валидируется и активируется через безопасный reload.

### Наблюдаемость и аналитика

- Геоаналитика запросов и событий.

## Быстрый запуск

Установка и обновление выполняются одной командой:

```bash
curl -sSL https://raw.githubusercontent.com/septumcore/SeptumCore_WAF/main/install.sh | sudo bash
```

Что делает инсталлятор:

- Подготавливает рабочую директорию `/opt/septumcore-waf`.
- Обновляет `install.sh` и `docker-compose.yml` из репозитория релиза.
- Устанавливает Docker (если отсутствует).
- Генерирует `.env` с `SESSION_SECRET` и параметрами PostgreSQL.
- Подготавливает права и структуру директорий (`waf-logs`, `waf-nginx`, `acme-challenge`, `waf-cache`, `waf-html`).
- Поднимает контейнеры `main-waf`, `waf-backend`, `waf-db`.

## Доступ к панели

- URL: `http://<IP_СЕРВЕРА>:9001`
- Логин: `admin`

Если пароль неизвестен или требуется ротация:

```bash
docker exec -it waf-backend /app/septumcore -reset-user admin
```

Установка своего пароля:

```bash
docker exec -it waf-backend /app/septumcore -reset-user admin -new-pass "ВашНовыйПароль123!"
```

## Архитектура релизного контура

- `main-waf` — фронтовый WAF-контейнер, принимает трафик на `80/443`.
- `waf-backend` — API и панель управления на `9001`.
- `waf-db` — PostgreSQL для конфигурации, событий и аудита.
- `worker-agent` (Опционально) — удаленные агенты (Data Plane), управляемые Master-нодой.

```bash
cd /opt/septumcore-waf && docker compose up -d --remove-orphans
```

## Рекомендации по безопасности

- Сразу смените пароль администратора.
- Ограничьте доступ к порту `9001` по IP (VPN/office whitelist).
- Оставьте открытыми наружу только нужные порты (`80/443` и бизнес-порты стримов).
- Регулярно выполняйте обновление (повторный запуск install-команды).

## Планы развития (Roadmap)

Мы прислушиваемся к комьюнити и постоянно развиваем SeptumCore WAF. В наших ближайших планах внедрение функций, которые сделают работу с защитой еще удобнее:
- **Уведомления в мессенджеры:** Интеграция с Telegram и Slack для получения мгновенных алертов о критических атаках, недоступности серверов и массовых блокировках.
- **Современные Captcha:** Поддержка Cloudflare Turnstile, hCaptcha и Yandex SmartCaptcha для страницы "Under Attack", чтобы пропускать живых людей без раздражающих картинок.
- **Поддержка 2FA (MFA):** Внедрение двухфакторной аутентификации (TOTP) для дополнительной защиты входа в панель управления.
- **Автоматические отчеты:** Генерация красивых PDF-отчетов по уровню безопасности и трафику за неделю или месяц.
- **Webhooks & API ключи:** Удобная интеграция с вашими внутренними пайплайнами и CI/CD (Terraform, Ansible, GitLab).
- **High Availability (HA) для WAF-нод:** Синхронизация состояний (лимиты HTTP Flood, активные баны IP) между независимыми нодами кластера в реальном времени.
